남서울지방정교회 V5.3

변경사항
- 기타임원 카드의 검정 원 아이콘 제거
- 월례회 소식지 PDF를 모바일 호환용 이미지-평탄화 PDF로 교체
- 일반 사용자 연락처: 앞 번호를 ***로 표시 (예: ***-1234-5678)
- 실제 전화번호는 APP_DATA에 평문으로 저장하지 않고 AES-GCM 암호화 데이터로 저장
- 관리자 암호 입력 시에만 전체 연락처 표시
- 메뉴 '시설·본영' -> '본영·영문·시설'
- 엑셀 기준 영문별 담임사관/목양사관 명단 추가
- 지방본영/사회복지시설 표는 별도 하단 표시

주의
- GitHub Pages는 정적 사이트입니다. 이번 버전은 전화번호를 암호화해서 노출 위험을 크게 낮추지만,
  서버 기반 로그인/권한관리와 동일한 수준의 접근통제는 아닙니다.
- 관리자 암호는 이 README에 저장하지 않습니다.
