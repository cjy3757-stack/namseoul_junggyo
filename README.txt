남서울지방정교회 스마트 행정시스템 V3.0.2

이번 수정의 핵심
- V3.0에서 등록한 service worker가 예전 index.html을 계속 캐시해서 새 파일을 올려도 먹통 화면이 유지될 수 있던 문제를 수정했습니다.
- 이전과 동일한 sw.js 경로에 '캐시 제거용 service worker'를 넣었습니다.
- 설치 즉시 기존 Cache Storage를 삭제하고, 열린 앱 페이지를 ?v=302 주소로 다시 불러온 뒤 service worker 자체를 해제합니다.
- 앱 화면에도 '캐시초기화' 버튼을 추가했습니다.

GitHub 적용 방법
1. 저장소 루트의 기존 파일을 이 ZIP 내부 파일로 모두 교체합니다.
2. 특히 sw.js 파일이 저장소 루트에 반드시 있어야 합니다.
3. Commit changes 후 GitHub Pages 배포가 끝날 때까지 잠시 기다립니다.
4. 처음에는 주소 뒤에 ?v=302 를 붙여 접속합니다.
   예: https://계정.github.io/저장소/?v=302
5. 한 번 새로고침합니다.
6. 상단에 '정상 동작 중 · 회원 89명 데이터가 로드되었습니다.'가 나타나면 정상입니다.
7. 그래도 이전 화면이면 브라우저의 해당 사이트 데이터 삭제 후 다시 접속합니다.

중요
- 이번 버전은 PWA 오프라인 캐시를 의도적으로 끈 안정화 버전입니다.
- 정상 동작이 확인된 다음, 안전한 network-first 방식으로 PWA를 다시 넣는 것이 좋습니다.
