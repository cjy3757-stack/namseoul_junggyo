# 남서울지방정교회 스마트 행정시스템 V3.0

## GitHub Pages 배포
1. ZIP 압축을 풉니다.
2. 새 GitHub 저장소에 이 폴더 안의 파일들을 모두 업로드합니다.
3. Settings > Pages > Deploy from a branch > main / (root) > Save
4. 생성된 주소로 접속합니다.
